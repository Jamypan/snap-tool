方案 B

极简启动器 · 键盘优先

假设主力用户是「一秒钟截图、复制、关掉」的效率党。整套界面砍到只剩一个输入框和一张命令表： 打开就是搜索框，输「框」「滚」「取」直接过滤，回车执行，Esc 关闭。视觉上接近纯黑白， 只在选中项留一点蓝。功能不减少——七个常用命令摆在首页，低频命令靠输入唤出。

黑白灰 + 单一蓝 #2F6BFF 无卡片、无分割线堆砌 键盘可达（↑↓ / Enter / Esc） 窗口更小更快

1主窗口 · 变成一个搜索框

窗口缩到 700×520，启动即聚焦输入框。第一组是四个截图命令（框选 / 窗口 / 全屏 / 滚动长截图）， 第二组是编辑与输出（OCR 取字 / 贴图到桌面 / 打开保存目录）， 第三组折叠成「更多命令」一行，输「热」「语言」「平滑」等关键词才出现。 底部一行常驻快捷键提示和托盘状态。

2标注编辑器 · 一条工具栏 + 浮动样式面板

工具栏压到 46px 一行：左边是绘图工具（选中态用黑底反白，视觉最强）， 右边是「取字 / 撤销 / 旋转 / 复制 / 保存」。样式面板继续做成浮动小窗， 但改成白底 + 更圆角 + 更轻阴影，跟在光标附近，避免像现在这样遮住画面。

3截图遮罩 · 底部半透明 HUD

框选完成后，选区下方浮出一条深色半透明胶囊 HUD（Windows 11 截图工具同款观感）： 左边显示选区尺寸，右边是「复制 / 编辑 / 取消 / 确定」四个圆形按钮。 深色浮层压在亮色桌面上，识别度最高，且不遮住选区内容。

520 × 300
按钮顺序：复制原图（不打开编辑器）→ 进编辑器 → 取消 → 确定 ✓。选区四角保留 8 个控制柄可调大小。
这套方案适合谁：把截图当「系统级快捷操作」的重度用户，一天按几十次。 代价：鼠标用户没有大按钮可点，所有命令都得先打字或方向键， 对完全不懂快捷键的新手反而更难用；并且现有「菜单栏 + 三模式按钮 + 热键卡」的结构基本要重写， snapui.py 的 _build_body 需要整体重做。
