默认截图模式：从设置项改为列表单选

改动两处：右列「设置」里删掉「默认截图模式」那一行（原来点一下循环切换）， 把选择权挪到左列四个截图模式的右侧，用单选圆点表示。 三套图的差别不在配色，而在圆点的表达方式和点击语义。

方案 1行尾纯圆点改动最小，视觉最轻

圆点只表示状态。点圆点 = 设默认（面板不关、不截图）；点行其余位置 = 照原样直接截图。 选中的行保留浅橙底，圆点实心橙。没有多余文字，含义靠鼠标悬停时的提示气泡解释。

好在哪行高、行宽、右列一行都不动，只给四个模式行补一个圆点。PySide6 里就是给 PanelRow 加一个 QRadioButton，接管它的点击，不让事件冒泡到整行。改一天能上。
问题圆点本身没有文字说明，新用户不知道能点。悬停提示是唯一解释手段，触屏或快速操作时等于没有。

方案 2圆点 + 「默认」列含义写在明面上

在「截图」分组标题右侧加一个 10px 的灰色列头「默认」，四个圆点正对着它排成一列； 选中的行在圆点左边恢复原来的「默认」二字。这样不用悬停也知道这一列是干什么的。

好在哪信息零损失——原来的「默认」标签没删，只是从纯文字变成「圆点 + 文字」。行尾用固定 74px 宽右对齐，圆点位置不随文字出现而左右跳。
问题行尾占用变宽，模式标题的可用宽度少了约 74px；「滚动长截图…」这种长标题在窄语言（如德语）下会先被挤。

方案 3整行即选择交互最清楚，代价最大

语义反过来：点整行 = 设为默认（不再立刻截图）。要截图按底部的「开始截图」按钮，或者鼠标移到某行时，行尾滑出一个「立即截图」小按钮。 「滚动长截图」不是模式而是动作，从选择组里摘出来，右侧改成箭头。

好在哪「选模式」和「开始截图」彻底分开，不会误触。四个圆点的语义和系统单选按钮一致，零学习成本；「滚动长截图」归位成动作行，逻辑也更顺。
问题多一步操作。熟练用户原来「点一下就截」变成「先选中再按热键」。必须保留 Alt+Z 和行内悬停按钮这两个捷径，否则是退步。
