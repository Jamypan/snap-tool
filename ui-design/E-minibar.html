迷你悬浮条 · 不占屏的工具

默认根本不弹「主窗口」——只在屏幕底部浮一条 420×64 的圆角小条，像 macOS 的程序坞。 点一下才展开模式菜单，用完自动收起。编辑器也去掉标题栏和菜单栏， 画布占满整个窗口，工具全部收进底部悬浮 Dock。

奶油白 #FBFAF7 暖橙 #F97316 大圆角 16–20px 毛玻璃 + 柔投影 主窗口 ≈ 一条 Dock

1主窗口 · 一条 64px 高的悬浮条

常态只占屏幕底部一小块（可拖到任意位置、可贴边隐藏）。条上只有： 图标 + 框选 / 窗口 / 全屏三个模式按钮 + 长截图 + 贴图 + 设置。 点模式按钮向上弹出带说明的模式卡（需要看解释的人才展开）， 老用户直接点按钮截图，不经过弹层。

2标注编辑器 · 无菜单栏 + 底部 Dock

窗口没有标题栏和菜单栏，只有右上角两个胶囊按钮（保存 / 关闭）。 底部悬浮 Dock 承载 7 个标注工具 + 撤销 + 贴图 + 复制； 选中标注时 Dock 正上方再浮出一条样式条（颜色、线宽、透明度）， 不做侧边栏，画布永远占满窗口。

3截图遮罩 · 贴着选区右下角的迷你条

选区边框用暖橙色，控制柄改成圆点（和 Dock 的圆润语言一致）。 确认工具条不再居中，而是吸在选区右下角——鼠标松手的位置就在附近，移动距离最短。 选区尺寸单独显示在选区左上角外侧。

450 × 240
贴边时工具条自动向内翻（现有「确定按钮就近浮出、贴边自动收缩」的逻辑可以直接复用）。
这套方案适合谁：把截图当肌肉记忆、不想让工具占屏幕的人。视觉上最「清新」， 也是三套里唯一把主窗口近乎消灭的。 代价：①悬浮条是无边框置顶窗口，要新写拖动、贴边隐藏、多屏定位 （可复用 v34 pinwindow.py 的浮窗骨架）； ②编辑器去掉标题栏后要自己实现拖动与缩放，且「文件 / 编辑 / 视图」菜单里的低频项要另找入口； ③样式条悬浮在 Dock 上方，双浮层重叠时的遮挡处理比方案 A/C 的常驻侧栏麻烦。
