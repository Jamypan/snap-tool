录屏功能：怎么接进现有界面

录屏是截图之外的一件平行的事，用顶部 Tab 分开，不往截图那两列里再塞东西。三种录屏方式照抄截图那套左右分栏：左边点立即录、右边点设为默认。真正录的时候主界面藏起来，只留一条悬浮控制条。

1顶部加「截图 / 录屏」切换

只多一行 Tab，右列设置跟着 Tab 换内容。老用户打开还是「截图」页，习惯不变；想录屏点一下「录屏」。两个功能各有各的热键：Alt+Z 截图、F9 录屏。

2三种录屏方式，照抄截图那套

左边整块点 = 立刻用这种方式开录；右边窄条点 = 只设为默认，不开录。和截图行一模一样，不用重新学。默认方式同一时刻只有一行选中。

3框选：拖完就录

屏幕上盖一层半透明遮罩，拖动出虚线框，框的上方实时显示宽×高。松开鼠标立刻开始录，不用再点确定。

5录制中：只留一条控制条

一点开始录，主界面自动隐藏（免得把自己录进去），屏幕边缘一圈红框表示在录，底部悬浮条显示计时、声音电平、暂停、停止。再按一次 F9 也能停。

复用现成东西：三种方式的左右分栏、默认圆点、Tab、开关、行样式，界面组件截图页都已有，录屏页是同一套。录屏新加的只有：顶部 Tab、悬浮控制条、选区尺寸标注、红框。
声音怎么存沿用老逻辑：系统声音 / 麦克风两个开关，整合到视频还是分开存成 WAV 仍旧每次录制前弹一次确认。帧率、保存目录、F9 热键都接到 screen-recorder 已有实现。
需要你定的两点：① 摄像头画中画要不要并进来（目前独立录屏软件里有，本稿先按「不加」处理）；② 框选录屏时是否允许录屏途中移动/缩放选区（本稿按「不允许，松开即固定」处理）。
