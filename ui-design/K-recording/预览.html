截屏助手 · 录屏功能静态设计

在现有 J 版界面上加录屏：顶部切「截图 / 录屏」，录屏也有框选 / 窗口 / 全屏三种方式，沿用同一套左右分栏和视觉风格。纯静态设计稿，未改任何程序代码。

① 主界面 · 录屏页顶部 Tab 切换，三种录屏方式 + 声音开关 + 录制设置，底部「开始录屏」。打开 HTML
② 交互说明5 个关键点，讲清录屏怎么接进现有界面。打开 HTML
③ 框选录屏拖动出选区，实时显示尺寸，松开即开始录。打开 HTML
④ 窗口录屏悬停整窗高亮，单击录这一个窗口。打开 HTML
⑤ 录制中 · 悬浮控制条主界面隐藏，屏幕红框 + 底部控制条（计时 / 电平 / 暂停 / 停止 / F9）。打开 HTML
设计取舍：录屏作为与截图平行的一页，靠 Tab 切换，不往截图两列里加行。三种方式直接复用截图那套「左启动 / 右设默认」的分栏，学习成本为零。
待你拍板：① 摄像头画中画是否并入本界面（本稿按不并入）；② 框选录屏是否允许录制中调整选区（本稿按松开即固定）。
