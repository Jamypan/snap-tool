截屏助手 · 六套界面方案

共两批。第一批 A/B/C：A 是暖白 + 薄荷绿的卡片式仪表盘，B 是纯黑白 + 单点的极简启动器，C 是深色侧栏 + 历史墙的工作台。 第二批 D/E/F：D 对齐 Windows 11 系统原生 Fluent，E 把主窗口缩成一条迷你悬浮条，F 把截图流程显性化成三步向导。 每套都画了主窗口、标注编辑器、截图遮罩工具条（F 多一张输出页）。

第二批 · D / E / F

方案 D

Windows 11 Fluent

Mica 底 + NavigationView + 设置式列表，完全对齐系统截图工具。

像系统自带，分发给别人零解释成本 CommandBar 图标+文字，不再只靠 tooltip QSS 可近似，但控件要自绘一批
打开完整设计稿 →
方案 E

迷你悬浮条

主窗口缩成 64px 悬浮条，编辑器去标题栏，工具全收进底部 Dock。

最省屏幕，视觉最「清新」 样式条悬浮在 Dock 上方，画布占满窗口 要新写无边框浮窗拖动 / 贴边隐藏
打开完整设计稿 →
方案 F

三步向导

选区域 → 标注 → 输出，步骤条贯穿三个窗口，每步只有一个主按钮。

把现有流程摆到明面上，新手不迷路 工具按「圈重点/写说明/遮隐私」分组 后端零改动，只需流程状态 + 保留快捷键捷径

第一批 · A / B / C

方案 A

柔和卡片仪表盘

四张大卡片承载所有截图方式，去掉菜单栏，热键降级成一行设置。

最不容易出错，新手零学习成本 编辑器右侧常驻属性栏，不再弹窗挡画面 改动最小：只动 snapui.py
打开完整设计稿 →
方案 B

极简启动器

主窗口就是一个搜索框 + 命令表，输关键词过滤，回车执行。

最高效，一秒截图复制关掉 编辑器工具栏压到一行 46px 改动最大：主窗口基本重写
打开完整设计稿 →
方案 C

侧栏工作台

左侧导航分组，右侧内容区带最近截图历史墙，可回看再标注。

适合反复对比同一批截图 编辑器 Figma 式三栏 + 检查器 需新增截图历史存储（唯一动后端的）

六套方案都只覆盖界面层：遮罩选区、标注内核、取字、旋转镜像、贴图这些既有逻辑不用动 （C 的历史墙与 E 的悬浮条贴边是仅有的两处新增交互能力）。 落地时建议先挑一套做主窗口，编辑器与遮罩工具条可以混搭——例如 F 的步骤条 + D 的 CommandBar，或 A 的主窗口 + C 的检查器。
