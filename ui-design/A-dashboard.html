方案 A

柔和卡片 · 浅色仪表盘

面向「不想记快捷键、只想点一下」的普通用户。把现有主窗口的菜单栏拆成四张大卡片， 常用操作全部收进可视区域，热键与默认模式降级为一行轻量设置。全局只用一种薄荷绿， 白色卡片浮在浅灰绿底上，信息层级靠留白而不是边框和分割线。

主色 薄荷绿 #0FA678 大圆角 12–14px 去菜单栏 图标 + 中文双通道 底部一行状态栏

1主窗口 · 一屏完成所有截图动作

窗口固定 860×560（比现在的 620×470 宽一点，为四张卡片横排留位置）。 顶部一栏只放品牌 + 运行状态 + 设置入口；中间四张卡片分别是 框选 / 窗口 / 全屏 / 滚动长截图，「滚动长截图」用实心绿渐变做视觉主入口； 底部一行是热键胶囊和默认模式。菜单栏全部取消——原来「文件 / 截图 / 设置 / 帮助」 里的低频项收进右上角齿轮的下拉菜单。

2标注编辑器 · 左侧工具条 + 右侧属性栏

现在编辑器把样式面板做成「选中才弹出」的浮动窗，容易挡住画面。这版改成 右侧常驻属性栏：选中矩形时右边显示线宽 / 填充 / 透明度滑块，选中文字时显示字号 / 背景 / 边框， 没选中时显示画布级操作。左侧竖排工具条按「形状 → 图像 → 输出」三段分组， 工具仍保持粘滞（画完不退出），当前工具常驻高亮。

3截图遮罩 · 确认工具条改为胶囊

框选 / 窗口模式确定后浮出的工具条，从现在的方块按钮改成 白色圆角胶囊，左端是四个常用输出（复制原图 / 进编辑器 / 钉在桌面 / 取消）， 右端是「确定 ✓」。位置仍固定在选区下方，不跟着鼠标跑。

520 × 300
选区四角仍是 8 个控制柄（图中示意只画了 4 个角），拖动可调整范围；确定后进标注编辑器。
这套方案适合谁：第一次用、不知道快捷键的用户。牺牲的是「一屏看全所有功能」的能力—— 低频项（命令行参数、语言、画笔平滑度）被收进齿轮菜单，需要多一次点击。 改动成本：只动 snapui.py 的 _build_body 与样式表， 后端逻辑、遮罩层、编辑器内核都不用动。
