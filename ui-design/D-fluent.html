方案 D · 第二批

Windows 11 Fluent · 系统原生观感

不做「自己的风格」，直接对齐 Win11 的设置应用：Mica 浅灰底、左侧 NavigationView、 内容区大标题、设置项一行一条、圆角 4–6px、控件全部用 WinUI 的按钮 / 下拉框 / 开关。 用户会觉得「这就是系统自带的截图工具」，没有陌生感。

Mica #F3F3F3 系统蓝 #0067C0 圆角 4–6px（不用大圆角） Segoe UI 字体 左侧选中指示条

1主窗口 · NavigationView + 设置式列表

窗口 960×600。左侧导航四项：截图、历史、贴图、设置，选中项左侧有 3px 蓝色指示条。 内容区顶部是大标题「截图」，下面三张小卡片对应三种模式（每张底部直接标热键）， 再往下是设置式列表：默认模式用下拉框、启动后显示主窗口用开关、保存目录用按钮—— 和 Win11 设置应用的控件完全一致。

2标注编辑器 · CommandBar + 折叠属性

顶部 CommandBar 用「图标 + 文字」的 WinUI 命令按钮（不再只有图标靠 tooltip）， 当前工具用浅蓝底标识。右侧属性区用 Expander 折叠面板：「线条与填充」「旋转」「画布」三组， 不用的组可以收起来，画面占比更大。

3截图遮罩 · 顶部模式条 + 选区确认条

完全照搬 Win11 截图工具的双条结构：屏幕顶部居中是模式切换条（框选 / 窗口 / 全屏 / 延迟）， 截完框选后选区正下方浮出确认条（复制 / 编辑 / 贴图 / 取消 / 确定）。 两条都是白底小圆角 + 深阴影，和系统截图工具手感一致。

模式条在框选过程中可切换，与现有「三种模式共用遮罩」的实现天然兼容。
这套方案适合谁：希望工具「像系统自带」的用户，尤其是给同事 / 家人分发时——没有学习成本。 落地难度：PySide6 里用 QSS 可以近似（Mica 背景可用 QWidget 底色 + Win32 DWM DWMWA_SYSTEMBACKDROP_TYPE 拿到真 Mica），但 NavigationView / Expander / Toggle 都要用 QListWidget + QToolBox + 自绘开关拼出来， 工作量比方案 A 大，且高分屏下的 1px 边框要按 DPI 缩放。
