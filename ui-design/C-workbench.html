侧栏工作台 · 可回看可复用

把截屏助手从「一个工具」变成「一个工作台」。左侧深色导航分四组（截图 / 取字 / 长图 / 贴图）， 右侧内容区放最近截图的历史墙——截过的图能直接翻出来再标注、再复制， 而不必每次重截。顶栏是全局搜索 + 一个醒目的截图按钮。

深色侧栏 + 浅色内容区 青绿 #00A389 历史截图墙 980×560 宽窗 信息密度中等

1主窗口 · 从「按钮页」变成「工作台」

窗口 980×560。左侧导航：截图（框选/窗口/全屏）、取字、滚动长图、贴图、历史、设置。 内容区自上而下是：搜索栏 + 主截图按钮 → 四个常用模式 → 最近截图九宫格（带尺寸、标注数、时间）。 历史项是这版的核心新增能力：点缩略图直接回到编辑器继续标注。

2标注编辑器 · 三栏专业布局

编辑器改成 Figma 式三栏：左 54px 细工具条（形状分组 + 图像操作）、 中间无限画布、右侧 222px 检查器面板常驻。检查器上半部分随选中对象切换 （矩形显示线宽/填充/旋转，文字显示字号/背景/边框），下半部分固定是画布级操作 （旋转、镜像、视图放缩）。底部状态栏显示缩放比与标注数量。

3截图遮罩 · 磨砂工具条

遮罩里也用同一套深色 + 青绿强调：选区边框为青绿色，四角控制柄为白底青边， 工具条改成毛玻璃半透明条，浮在选区正下方，与编辑器配色统一。

440 × 240
选区仍是 8 个控制柄可缩放；点「钉在桌面」直接贴到桌面并收起截图界面（沿用现有 v34 行为）。
这套方案适合谁：需要「反复对比同一张图」的场景——做设计、查资料、写文档时截好几张图对照着看。 代价：主窗口从 620×470 变成 980×560，占屏面积翻倍；而且「历史记录」需要新增一层 截图历史存储（当前程序只在「复制 / 保存」时落盘，没有统一的历史索引）， 这是三套方案里唯一需要动后端数据模型的。
