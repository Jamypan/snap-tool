# 截屏助手（Snap Tool）

一个模仿微信截屏体验的桌面截图工具。**纯原创实现，与微信无关**，不涉及任何逆向。

## 功能

- **启动即显示程序主窗口**（菜单栏、三种截图模式按钮、当前热键、默认模式设置）+ 托盘常驻，一眼就知道程序已启动
- **三种截图模式**：框选 / 窗口（悬停高亮、单击确认）/ 全屏
- **全局热键唤起**（默认 Ctrl+Shift+A，可在菜单里随时改成任意组合，配置自动保存）
- **帮助菜单**：使用说明、命令行参数、关于（含头像与联系邮箱）；命令行 `python snap.py --help`
- 全屏半透明遮罩 + 拖动框选，可拖动选区、拖八个控制点调整
- **抓屏前先隐藏本程序所有窗口**（主窗口、编辑器、工具条、样式面板等），等窗口彻底从屏幕上消失再抓，不会把半透明窗口影子拍进截图里
- 标注：矩形、椭圆、箭头、直线、画笔、马赛克、文字；工具栏按钮全部用图标表示，鼠标悬停有文字提示；**马赛克是纯像素化效果，没有可调样式，使用马赛克工具或选中马赛克时不会弹出样式面板**
- **矩形 / 椭圆四角缩放（v21）**：选中后外接矩形四角出现圆形控制柄，拖动任一角即可改变宽高与形状（对角固定、可拖过对角翻转、有最小尺寸保护）；截图遮罩和程序窗口编辑器都支持，画布放缩后手柄大小与命中范围保持不变；马赛克 / 线条等其它标注仍只能整体拖动或拉伸端点
- **形状旋转（v22）**：矩形 / 椭圆 / 文字选中后上方出现<b>旋转柄</b>，拖动即可绕自身中心任意旋转，按住 Shift 吸附 15°，也可在样式面板里用「旋转角度」滑块精确设定；菜单「编辑 → 旋转选中形状」提供 90° 步进（Ctrl+[ / Ctrl+]）。旋转后四角缩放柄与点选命中都跟着转，画布放缩后手感一致；马赛克、箭头 / 直线、画笔不旋转
- **整图旋转时文字一起转（v22）**：顺时针 / 逆时针 90° 时文字标注不再保持水平，字形与底图同步旋转，并按「文字包围盒中心」映射位置；镜像时字形保持可读（不做反字），方向按镜像取负。矩形 / 椭圆的几何由外接矩形映射完成旋转，自身角度保持不变；Ctrl+Z 可完整恢复角度
- **透明线条 / 填充透明度**：线条颜色新增「∅ 透明」色块，可画无边框图形；封闭图形启用填充后有 0~100% 不透明度滑块
- **文字背景透明度与背景边框（v23）**：文字背景色改用与椭圆填充色相同的交互方式——预设色块 + 独立的「背景透明度」滑块（0~100%，与填充透明度各自记忆、互不影响）；文字背景框新增「启用边框」，边框颜色可选预设色或「∅ 透明」（透明即无边框），并有独立的边框线宽与线型（实线 / 虚线 / 点线）。旋转文字时背景框与边框一起转，撤销同样可恢复
- **文字输入位置不跳（v24）**：输入框左上角与文字标注的基线坐标原本混用，导致回车提交后文字整体上跳约一个字高；现按 QLineEdit 实际样式几何换算基线，输入时看到的字与提交后绘制的字像素级重合。截图遮罩与程序窗口编辑器通用，画布放大 / 缩小、高 DPI 屏以及双击改字（含旋转文字）都不会漂移
- **画布视图放缩**：Ctrl+滚轮以光标为锚点缩放，菜单「视图(&V)」提供放大 / 缩小 / 1:1 / 适应窗口，中键拖动平移；只改显示比例，导出始终全分辨率
- **首次截图不卡顿（v28）**：启动后离屏预热字体 / 图标 / 光栅化 / 抓屏后端；遮罩显示时首帧同步绘制完成才开放鼠标输入（输入门闩），杜绝"框选都完成了画面才跳出来"的错位
- **标注工具粘滞（v31）**：在编辑器里选中任意标注工具（矩形 / 椭圆 / 箭头 / 直线 / 画笔 / 马赛克 / 文字）后，该工具按钮**保持亮起**，画完一个就能**接着画下一个**，不用每次重新点工具。**结束当前工具**有三种方式：**再点一次该工具按钮**（回到选择态）、**点其他工具按钮**（切换过去）、**单击右键**（画布内）。截图遮罩与程序窗口编辑器都支持；这样连续标注流畅，又不会误以为工具已退出
- **重复启动直接唤出窗口（v31）**：程序已在后台运行时再次双击程序 / 快捷方式，**不再弹「是否结束它并重新启动」对话框**，默认不重启，直接把已运行实例的主窗口显示出来；需要强制重启时仍可用 `python snap.py --restart` / `restart.bat`
- 确定选区后工具条最左侧点「复制」（v27）：直接把**原图**放进剪贴板，并**关闭截图编辑与截屏助手两个窗口**，只留托盘常驻；点「确定」才**打开截图编辑窗口**继续标注；全屏直截、滚动长截图完成时也会自动把原图放进剪贴板
- 进入编辑器后可继续标注，成图用 Ctrl+Enter / 工具条「复制」更新到剪贴板；也可另存为 PNG/JPG
- **滚动长截图（独立命令）**：主窗口按钮 /「截图 → 滚动长截图…」/ 托盘右键启动 → 悬停高亮并**单击目标窗口**（取其客户区，自动排除标题栏 / 边框）→ **立即自动向下滚屏**并模板匹配拼接成长图 → 预览另存；不框选、不进入编辑器。滚动中**左键单击暂停、再单击继续**，**右键单击结束**，点控制条「**确定 ✓**」或按 Esc 结束，**滚到底自动结束**
- **网页不易中途截断（v19）**：到底需连续 3 帧确认、匹配失败自动重试 2 次、模板取画面中部避开固定顶栏、滚轮步长自适应、每帧重新锁定光标；控制条显示帧数 / 高度 / 匹配分数，结束时托盘说明结束原因
- **长截图画质清理（v20）**：拼接期间自动临时隐藏**输入法工具条 / 候选窗**（结束必恢复，异常也不漏），光标改停在窗口右侧滚动条而不是画面中心，避免悬停链接触发浏览器左下角的 URL 提示条；捕获区底部预留安全行避开状态条；模板匹配改用中间列带 + 多候选 + 重叠区一致性验证 + ±2 行微调，消除浮层周期性重复、帧间大段重复带（「拼接缝隙」）与错位
- 程序窗口内 **OCR 取字**：识别文字按行盖回原文位置，可就地拖选 / 复制（见下方说明）
- **整图旋转 / 镜像**：顺时针 / 逆时针 90°、左右镜像、上下镜像，底图和已有标注一起变（v22 起**文字字形也跟着旋转**，不再保持水平），`Ctrl+Z` 可撤销，导出始终全分辨率
- **画笔 / 直线端点箭头**：画笔路径与直线的起点、终点可单独或同时加箭头，菜单或样式面板里设置
- **选定截图后统一进入程序窗口编辑**：框选 / 窗口截图先确认选区（可移动、拖控制点调整），点「确定」后把**裁好的那块图**送进一个普通程序窗口继续编辑；**全屏截图直接进程序窗口**，无需确定。窗口里可标注（矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字）、撤销、改样式、OCR 取字、复制、另存为文件，导出始终是全分辨率原图
- **「确定」按钮就近浮出、位置固定**：框选松手 / 窗口单击的瞬间，「确定 / 取消」浮在鼠标旁（贴屏幕边缘会自动收缩、不会镜像到对角）；之后鼠标移到别处点击，按钮保持不动
- **退出时静默**：托盘右键「退出」或主窗口「文件 → 退出」时直接安静退出，不再弹「已最小化到托盘，程序仍在运行」等任何提示，托盘图标也随之移除
- **单实例自愈**：重复启动先唤醒已有实例并显示主窗口；后台残留实例（有进程但没界面）可在弹窗里一键结束并重启，陈旧锁自动接管，不会再卡在「程序已经在运行」
- **内置离线中文 OCR（RapidOCR）**：PP-OCR 的 ONNX 模型随程序自带，完全离线、不上传、不依赖系统中文语言包，在程序窗口里把识别结果逐行盖回原文位置
- **8 种界面语言 + 启动时跟随系统语言**：简体中文 / 繁体中文 / English / 日本語 / 한국어 / Français / Deutsch / Español，切换后已打开的窗口立即刷新，菜单、工具提示、帮助、关于、命令行说明一起变（详见「界面语言」）
- **可打包成绿色版 exe**：无需安装包，解压即用、不需要 Python，见下方「Windows 绿色版 exe」

## 快速开始

双击 `run-silent.bat`（推荐，无黑窗口）或 `run.bat`，也可命令行 `python snap.py`。
**不想装 Python**：直接用绿色版发行包，解压后双击 `SnapTool.exe`（见「Windows 绿色版 exe」）。

启动后会弹出「截屏助手」主窗口，右下角同时出现托盘图标——**看到窗口就说明程序已成功启动**。
关闭主窗口只会最小化到托盘，程序继续运行；要彻底退出请用「文件 → 退出」或托盘右键「退出」。
界面默认跟随 Windows 显示语言，可在「设置 → 语言…」里切换 8 种语言（见「界面语言」）。

其他用法：

```
python snap.py --shot      启动后立刻截一次（使用默认截图模式）
python snap.py --restart   结束后台残留实例并重新启动（等价于双击 restart.bat）
python snap.py --selftest  运行自检（不进入界面）
python snap.py --help      打印命令行说明，不进入界面
```

## 提示「已经在运行」却看不到程序

程序是单实例 + 托盘常驻。以前只要后台还留着一个进程（哪怕窗口全被隐藏），就会一直弹「已经在运行」，用户却找不到托盘图标。现在按下面顺序处理：

| 情况 | 程序的行为 |
|---|---|
| 托盘图标被系统折叠 | 重复启动会**唤醒已有实例**并显示「截屏助手」主窗口；通知区点 `^` 展开也能找到图标 |
| 旧实例只留隐藏窗口（幽灵进程） | 弹窗会给出 PID 与启动时间，点「是」即结束后台实例并重启；也可直接双击 `restart.bat` 静默完成 |
| 进程已退出但锁 / 记录残留 | 用 `%APPDATA%\SnapTool\instance.json` 里的 PID + 进程创建时间校验，判定为陈旧锁，**静默接管启动**，不再提示 |
| 改了源码想用新代码 | 双击 `restart.bat`（或托盘右键「退出」后重跑 `run-silent.bat`） |

排查依据写在 `%APPDATA%\SnapTool\startup.log`：每次启动的 `probe err / 实例记录 / 判定结果` 都有记录。

> 实现上用 `WinDLL(use_last_error=True)` + 调用前 `SetLastError(0)` 读取 `CreateMutexW` 的结果，避免上一次 Win32 调用残留的错误码 183 造成误报；HANDLE 显式声明为 64 位，避免被 ctypes 默认 `c_int` 截断。

## 运行环境

- Windows 10/11
- Python 3.10+（已在 3.13 验证）

安装依赖（源码运行）：

```
pip install PySide6 Pillow numpy rapidocr onnxruntime
```

可选依赖（按需安装，代码里都是懒加载，缺了只会影响对应功能）：

- `opencv-python`：滚动长截图的图像拼接
- `paddlepaddle` + `paddleocr`：**第二 OCR 后端**，中文效果好但体积很大（380 MB+），绿色版 exe 不含
- `winrt-*`：Windows 内置 OCR 兜底（还要求系统装了 `zh-CN` OCR 语言包）
- `pytesseract` + 系统 Tesseract：最后兜底

`run.bat` / `run-silent.bat` 会**优先使用 PATH 里已装好 PySide6 的 `python` / `pythonw`**；若 PATH 里的解释器缺依赖，则回退到开发机自带的 Python 环境（保证原有部署不受影响）；两者都不可用会给出明确报错。从仓库 clone 下来后，建议先建虚拟环境装好依赖，再双击启动脚本。

## Windows 绿色版 exe（分发给其他人）

**不需要做安装包**：程序不写系统目录、不注册 COM/服务/驱动、不需要管理员权限；配置存 `%APPDATA%\SnapTool\`，截图存用户图片目录。发一个压缩包就够了。

构建（开发机，需先装好依赖）：

```
pip install PySide6 Pillow numpy opencv-python pyinstaller rapidocr onnxruntime
pyinstaller --noconfirm --clean SnapTool.spec
```

也可以直接双击 `build-exe.bat`（自动挑选装齐依赖的解释器）。产物是 `dist\SnapTool\` 里的 `SnapTool.exe` + `_internal\`，**v25 实测约 265 MB / 280 个文件**；压成 zip 后约 **117 MB**（v24 是 294 MB / 658 个文件、zip 130 MB）。本机已生成 `dist\SnapTool-win-x64.zip`；`build/` 与 `dist/` 按 `.gitignore` 不入库，随时可用 `build-exe.bat` 重建。

**分发时把整个 `SnapTool` 目录压缩成 zip / 7z，不要只单独拷 exe。**

验证产物（不进界面）：

```
SnapTool.exe --selftest
```

结果写入 `%APPDATA%\SnapTool\selftest.log`；看到 `RESULT: PASS` 且 `OCR backend=rapidocr` 即说明模型与 DLL 都收齐了。

构建要点：

| 项 | 说明 |
|---|---|
| OCR 模型 | 3 个 `.onnx`（约 31 MB）随包自带，**不联网、不上传、不依赖系统中文语言包** |
| 排除 Paddle | `SnapTool.spec` 显式排除 `paddle / paddleocr / paddlex / ppocr`，否则懒加载 import 会把 380 MB+ 框架拖进产物 |
| 体积裁剪 | 早期剔除 cv2 的两份 ffmpeg 视频 DLL、Qt 的 QML/PDF/软件 OpenGL/翻译文件（省约 97 MB）；**v25 再删 378 个冗余文件**：Qt 可选插件（只留 `qwindows` + ico/jpeg/webp + windows 样式）、onnxruntime 自带示例模型 / tools / transformers / quantization 源码副本、`*.dist-info` / `py.typed` / `.pyi`、chardet 语料、certifi 根证书，以及程序根本不用的 `cryptography/_rust.pyd`(9.44 MB) 与 `PIL/_avif.pyd`(7.53 MB)。目录 294 → 265 MB，zip 130 → 117 MB，功能不变 |
| 刻意保留 | 3 个 PP-OCR 模型、`cv2.pyd`、Qt6Core/Gui/Widgets/Network、OpenSSL 运行库、LICENSE / ThirdPartyNotices（第三方许可证随附） |
| 字节码优化 | 保持 `optimize=0`：试过 `optimize=2`（-OO 去 docstring），numpy 的 `add_docstring` 装饰器拿到 `None` 会直接 `TypeError`，冻结版启动即失败 |
| UPX | 保持 `upx=False`：onnxruntime / OpenCV 的 DLL 压缩后容易加载失败 |
| 无控制台 | `--windowed`，不会弹黑框；程序内异常不会打到 stderr（RapidOCR 日志已静默） |
| 首次取字 | 加载模型约 1~5 秒，之后引擎常驻缓存 |
| 杀软误报 | 未签名的 PyInstaller exe 可能被误报；正式分发建议加代码签名 |

想要开始菜单快捷方式 / 开机自启 / 卸载入口时，再用 Inno Setup 把这个目录包一层即可，**不需要改任何 Python 代码**。

## 程序窗口与三种截图模式

**主窗口**：启动即显示。顶部显示当前热键与「默认模式」，下面三个按钮可立即按指定模式截图；
菜单栏为「文件 / 截图 / 设置 / 帮助」。关闭窗口 = 最小化到托盘，不退出程序。
截图时程序会临时隐藏自己的主窗口、帮助窗口、预览窗口，避免被拍进图里，结束后自动恢复。

| 模式 | 操作 | 适用场景 |
|---|---|---|
| 框选截图 | 按住左键拖出矩形，松手后可拖选区、拖八个控制点微调 | 截局部内容（默认） |
| 窗口截图 | 移动鼠标，目标窗口高亮并显示标题与尺寸，**单击确认**；右键或 Esc 取消 | 完整截下某个窗口 |
| 全屏截图 | 进入时自动选中整个虚拟屏幕，无需拖选 | 整个桌面 / 多显示器合屏 |

窗口模式用 Win32 `EnumWindows` + DWM 可见边框定位，会自动去掉 Win10/11 的透明阴影，
并跳过本程序自己的窗口；三种模式确定选区后共用同一个标注编辑器（标注 / 取字 / 复制 / 保存一致）。

**默认模式**：主窗口的组合框决定**全局热键和托盘「截图」**使用哪种模式，选择后自动写入配置、重启仍有效。
三个大按钮和「截图」菜单则是一次性按指定模式截图，不改默认。

## 选定截图后统一进入程序窗口编辑

无论哪种模式，截图内容选定后都会进入同一个「程序窗口」（`截屏助手 - 截图编辑`）继续操作，遮罩层只负责**选区域**，不做标注：

- **框选 / 窗口截图**：选定区域后会浮出「**确定 / 取消**」按钮。此时只能**拖动选区、拖八个控制点调整大小**，不能（也不需要）在遮罩上画标注。点「确定」（或回车）把**裁好的那块图**送进程序窗口；点「取消」（或 Esc）放弃整次截图。
- **全屏截图**：自动选中整个虚拟屏幕，**直接进程序窗口**，没有选择/确定这一步，窗口里就是整张桌面。

进入程序窗口后：

- 这个窗口里**复用同一套标注工具**：矩形、椭圆、箭头、画笔、马赛克、文字，支持选中、拖动、拖箭头端点、双击文字改内容、撤销（Ctrl+Z）、样式面板改线条/颜色/字号等。
- 同样支持 **OCR 取字**（菜单「编辑 → OCR 取字」或工具条「取字」），结果**逐行盖回原文位置**；以及**复制到剪贴板**（Ctrl+Enter / Enter / 工具条）、**另存为 PNG/JPG**（Ctrl+S / 文件菜单）。
- 关键保证：**导出始终是原图全分辨率**。窗口里显示是缩放后的预览，但标注坐标以物理像素（原图分辨率）存储，`compose()` 合成时按原图尺寸渲染，不会因窗口缩放而损失清晰度。框选/窗口确认后送进窗口的就是裁剪后的那块图，导出也只会是这块区域；全屏送进来的则是整张桌面。
- 关闭编辑器窗口（标题栏 × / Esc / 文件菜单「关闭编辑器」）后，程序主窗口会自动重新显示。

> 适用场景：截完选定内容后想慢慢圈重点、加箭头、写说明，再一次性复制或保存；或需要对整张图做多步标注、来回撤销调整。

## 图像变换与画笔箭头

两个功能都在**程序窗口编辑器**里（选定截图、点「确定」之后）。

### 整图旋转 / 镜像

工具栏里「撤销」右侧用竖线隔开的一组按钮就是整图变换，与「取字 / 保存 / 复制」等命令按钮排在一起：

| 入口 | 效果 |
|---|---|
| 工具条「顺旋」（Ctrl+R） | 宽高互换，画面顺时针转 90° |
| 工具条「逆旋」（Ctrl+Shift+R） | 宽高互换，画面逆时针转 90° |
| 工具条「左右」（Ctrl+H） | 水平翻转 |
| 工具条「上下」（Ctrl+Shift+H） | 垂直翻转 |
| 编辑 → 图像变换 → … | 菜单入口，效果同上 |

- 变换作用于**整张图：底图 + 已有标注一起变**，不会只转底图让标注错位。矩形 / 椭圆 / 马赛克、箭头端点、画笔路径、文字位置都按对应公式换算，旋转 90° 时矩形宽高互换。
- 马赛克会在变换后重新取样，不会残留旧图；`Ctrl+Z` 可撤销变换，且顺序正确（变换后新画的标注先撤销，再撤销变换本身）。顺时针转 4 次可回到原图。
- 导出始终是全分辨率（旋转后是变换后的新分辨率），不因窗口预览缩放而损失清晰度。
- 文字标注只移动位置，字形仍保持水平可读——刻意这样设计，避免文字跟着转 90° 后没法看。

### 画笔 / 直线端点箭头

- 「直线」工具画的是一条可两端加箭头的直线；「画笔」画的是自由曲线，两端同样可分别加箭头。样式面板里的「起点加箭头 / 终点加箭头」对两者都生效。
- 菜单「编辑 → 端点箭头」有 4 个选项：**不加箭头 / 只加起点 / 只加终点 / 两端都加**。它既是新建画笔 / 直线的默认，也会立刻作用于当前选中的那条画笔或直线。
- 样式面板不用按钮打开：**选中标注会自动弹出**，或用菜单「编辑 → 样式面板」；无选中标注时勾选取的是新建默认，选中时改当前这一条。
- 箭头方向沿端点附近一小段路径的走向（稳定切线）：起点箭头朝路径外侧，终点箭头朝路径前进方向。鼠标采样很密时最后两个点可能只差 1~2px 甚至完全重合，方向按一小段弧长计算，不会被最后一个采样点带偏。线越粗箭头越大，用的是和「箭头」工具同一套实心三角。
- 整图旋转 / 镜像后箭头标记保留，方向跟着路径端点一起变。

## 自定义全局热键

右键托盘图标 →「设置热键…」，有两种改法：

- **按键录制**（默认打开即处于录制态）：点上方大按钮，按住 `Ctrl` / `Alt` / `Shift` / `Win` 中至少一个，再按一个主键，例如 `Ctrl + Shift + S`。录制到后按「保存」立即生效，无需重启。
- **手动选择**：勾选修饰键 + 在「主键」下拉框里选字母、数字、F1~F12、PrintScreen、方向键等。适合录制不到某些键（如部分 `Win` 组合被系统截走）的情况。

细节：

- 必须包含至少一个修饰键；只有主键的组合会被拒绝，避免把普通按键全局拦截掉。
- 保存时会实际向系统注册一次。若该组合**已被其他程序占用**或属于系统保留组合（如 `Ctrl+Esc`），会提示「无法注册」，旧热键保持不变，可以直接换一个再试。
- 打开设置窗口时会临时注销热键（防止录制时误触发截图），关闭窗口后自动恢复。
- 配置保存在 `%APPDATA%\SnapTool\settings.json`（同时存热键与默认截图模式，互不覆盖），重启后仍然有效；文件损坏或缺失会自动回退到 `Ctrl+Shift+A` + 框选模式。设置环境变量 `SNAPTOOL_HOME` 可把配置目录改到别处（便携版可用）。
- 注册时带 `MOD_NOREPEAT`，长按不会连续弹出截图。

## 关于 OCR（取字）

点「取字」后**编辑器窗口不会关闭**，每一行识别文字会按识别框（bbox）盖回它原本在图中的位置：

- 每个文本块都是只读但可选中的文字，可鼠标拖选、`Ctrl+A` 全选、`Ctrl+C` 复制，也可用取字工具条上的「复制选中」「复制全部」。「复制全部」按从上到下、同排从左到右的阅读顺序拼接（中文之间不加空格，英文之间加空格）。
- 文本块用接近不透明的浅色底盖住原字，避免「同一行字叠两遍」发糊；字号自动跟随原文字高度。OCR 的 bbox 是原图物理像素，窗口里显示的是缩放预览，行块位置按 `居中偏移 + bbox × 缩放比` 换算；**改变窗口大小后行块会重新盖回**，不会错位。
- 取字工具条显示「识别到 N 行」和后端名，默认浮在窗口顶部，若压住了文字行就自动改放底部。取字期间标注工具条和样式面板会收起。
- 复制后显示「已复制到剪贴板 ✓」，约 0.4 秒后自动收起文本层，回到正常编辑态（剪贴板变化、按钮、Ctrl+C、右键复制都会触发）。
- 点「返回」或按 `Esc` 只收起取字层，**不会关闭编辑器窗口**；识别**过程中**按 `Esc` 取消本次取字，迟到的识别结果不会再弹出。取字期间回车不会把截图直接复制走。
- 识别中显示「正在识别文字…」；失败或没识别到文字时给轻提示，不再弹独立窗口。
- 若后端不返回位置坐标（个别兜底场景），自动降级成整块文本面板，仍可拖选复制。

OCR 默认走 **RapidOCR**（PP-OCR 模型的 ONNX 版，由 ONNX Runtime 推理），返回行级 bbox + 置信度；模型随程序自带、完全离线、不依赖系统中文语言包，首次取字加载模型约 1~5 秒，之后引擎常驻缓存。

后端按可用性依次降级：`RapidOCR → PaddleOCR → Windows 内置 OCR → Tesseract`。绿色版 exe 已排除 PaddleOCR，实际链路是 `RapidOCR → Windows 内置 OCR`；后者要求目标机器装了 `zh-CN` OCR 语言包，且对倾斜 / 低对比度图片较弱，所以只作为兜底。

## 关于旧的打包命令

早期文档里的 `pyinstaller -F -w snap.py` **已废弃**，请用 `SnapTool.spec` + `build-exe.bat`：

- `-F` 单文件模式会把 PaddlePaddle 全家桶（380 MB+）拖进产物，且启动时解压几百 MB 到临时目录；
- 它不会收集 RapidOCR 的 `.onnx` 模型，换一台机器「取字」就会失败；
- 无控制台模式下 RapidOCR 的日志还可能往 `None` 写入（现已在 `snapback.py` 里静默处理）。

产物在 `dist/` 目录。
